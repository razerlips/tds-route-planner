# シー周遊プランナー（tds-route-planner）

東京ディズニーシーの1日の回り方を組み立てる、非公式のWebアプリです。

- 行きたいアトラクション・ショー・食事・グリーティング・ショップを選ぶと、ショーや予約の時刻を固定したまま、徒歩移動が短くなる順にスケジュールを作ります
- 公式サイトの当日ページから「パレード/ショー」「キャラクターグリーティング」をコピーして貼り付けると、時刻を取り込めます
- DPA／プライオリティパスの時間指定、朝イチ、優先、順番の指定、予定の確定に対応しています
- プランはブラウザ（localStorage）にだけ保存されます。サーバーには何も送りません
- バックアップ用のコードで、別の端末にプランを移せます

## 注意

非公式のファン製ツールです。株式会社オリエンタルランドおよび東京ディズニーリゾートの公式サービスとは関係ありません。
待ち時間・所要時間・場所・徒歩距離はすべて目安です。当日の公式アプリの情報で確認してください。

## 公開（Render）

依存関係もビルドもない、HTML 1ファイルの静的サイトです。

1. Render で **New → Blueprint** を選び、このリポジトリを接続する（`render.yaml` を読み込みます）
2. もしくは **New → Static Site** で、Build Command は空、Publish Directory は `.` にする

## ローカルで見る

`index.html` をブラウザで開くだけで動きます。
